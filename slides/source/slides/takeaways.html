IL–CO₂ solubility · sharing session

If you remember three things from this talk. First, combining quantum chemistry with machine learning is a workable way to predict CO₂ solubility. Second, how you test a model matters as much as the model: random splits overstate performance when the same liquid appears in training and testing. Third, check the inputs. A parsing mistake affected about half the ions and the score still looked excellent. These lessons carry over to any field that uses machine learning.
